# Stacktopolis

A satirical city-builder survival game about digital sovereignty, based on the [TechFreedom](https://techfreedom.eu) risk framework.

You're the CTO of a small European charity trying to keep operations running. Build your tech stack, survive increasingly absurd (but terrifyingly plausible) disasters across three risk lenses: **Jurisdiction**, **Business Continuity**, and **Surveillance**.

## Development

```bash
npm install
npm run dev
```
